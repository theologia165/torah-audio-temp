# Jubilees 2:1–3 — Geʿez AI reading prototype

This directory stores verse-level AI-generated MP3 readings for Jubilees 2:1–3.

## Text source

The Geʿez text is transcribed from the Open Siddur Project page:

- https://opensiddur.org/readings-and-sourcetexts/readings/jewish-readings/shavuot-readings/sefer-hayovelim-jubilees-preserved-in-geez/
- License stated by the source: CC BY-SA 4.0
- Verse range: Jubilees 2:1–3

Before scholarly publication, the text and word division should be checked against James C. VanderKam, ed., *The Book of Jubilees*, CSCO 510 (1989).

## Audio status

The files in `audio/` are synthetic readings generated with the OpenAI Speech API. They are pronunciation experiments, not recordings of Ethiopian Orthodox liturgical recitation and not an ecclesiastically authenticated pronunciation standard.

Model, voice, generation timestamp, and SHA-256 checksums are recorded in `audio/metadata.tsv`. The public page or player must disclose that the voice is AI-generated.
